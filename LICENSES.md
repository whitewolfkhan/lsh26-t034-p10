## Third-party dependencies

This project has **no third-party runtime dependencies**. It is built entirely
with vanilla HTML, CSS, and JavaScript, has no build step, and loads no external
libraries, fonts, scripts, or stylesheets from a CDN. All code in this
repository was written by the team.

Fonts are referenced only as CSS system-font fallbacks (e.g. Segoe UI, Georgia,
Consolas); no font files are bundled or downloaded.
